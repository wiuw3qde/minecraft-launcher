# MC 启动器 v0.2.4

**首个双平台版本。** 这一版正式提供 **macOS（Intel 芯片）安装包**，并让 Windows 与 macOS 从**同一个 Release** 各自收到属于自己的更新：Windows 读 `latest.yml` 下载 `.exe`，macOS 读 `latest-mac.yml` 下载 `.zip`。Windows 侧功能与安装方式**完全不变**。

> 版本进位规则照旧：`0.X.9 → 0.(X+1).0`，本次为 `0.2.3 → 0.2.4`。

## 🖥 macOS（Intel x64）首发

移植的原则是「原功能不动」：不为 Mac 单独做一套界面，也不改 Windows 已有的任何行为，只把**确实因操作系统而异**的地方补齐。

- **Java 链路**：自动下载改为按平台取 Adoptium `mac/x64` JDK；探测 `/Library/Java/JavaVirtualMachines`、Homebrew、`.jdk/Contents/Home/bin/java`；手动选择文件不再只认 `.exe`；解压 JDK 时恢复 Unix 可执行位（`bin/java` 没有 `+x` 游戏就起不来）。
- **游戏目录**：macOS 使用官方的 `~/Library/Application Support/minecraft`，从 HMCL / 其它启动器导入配置时也会扫对应目录。
- **自动更新**：新增独立生成 `latest-mac.yml` 的 Mac 构建脚本。macOS 下的更新器只读这个清单、且**强制要求 `.zip`**（只有 `.dmg` 会静默更新失败），因此 Mac 包同时提供 `.dmg`（安装用）与 `.zip`（更新用）。
- **联机（陶瓦）**：改用 `macos-x86_64` 资产；可执行文件支持无扩展名的 Mach-O 与 `.app`，自动去隔离属性；结束进程改用 POSIX 信号，不再调用 `taskkill`。
- **其它**：网页与微软登录的 User-Agent 按平台生成，不再向站点误报 Windows；设置页「环境信息」正确显示 macOS。

### Mac 用户必读（首次使用）

1. 本版是 **ad-hoc 签名、未公证**。首次打开若被系统拦下，请在 Finder 里**右键 App →「打开」**；或终端执行 `xattr -cr "/Applications/MC 启动器.app"`。自动更新替换 App 后可能再次被拦，同样处理即可。
2. **首次联机需要装一次系统组件**：联机页点「打开系统组件安装包」，输入管理员密码完成 `.pkg` 安装（它会装好创建虚拟网卡 TUN 所需的后台守护进程），然后**完全退出并重启启动器**再启动联机。
3. **仅支持 Intel 芯片（x86_64）**。Apple Silicon（M 系列）本轮不作为支持目标：x64 包可借 Rosetta 2 运行，但联机的系统授权路径不同，尚未验证。

## 🔒 发布链路加固

双平台共用一个 Release 后，出现了一类新的、很隐蔽的风险：`dist/` 里残留的**上一版更新清单**会被无条件上传，覆盖新版清单，导致某个平台收不到更新或反复提示更新。本版在发布脚本里加了强制校验：

- 上传前核对 `latest.yml` / `latest-mac.yml` 里的版本号与本次发布版本是否一致，不一致直接中止；
- 有 Windows 安装包就必须有 `latest.yml`，有 Mac 安装包就必须有 `latest-mac.yml`；
- 有 `latest-mac.yml` 却缺 `.zip` 时拒绝发布；
- 支持「Windows 先发、Mac 后补」的分侧发布，不会误要求某一侧具备另一侧的产物。

配套新增 `tests/publish.test.js`（9 组场景）与 Mac 真机验收手册 `docs/MAC_INTEL_GUIDE.md`。

## 🐛 修掉一个会连累 Windows 的打包回归

Mac 移植时曾给 electron-builder 的 `build.mac` 加了非法的 `arch` 字段（架构只能由命令行 `--x64` 指定，配置里没有这个键）。配置校验是**全平台共用**的，结果不仅 Mac 打包会挂，连 **Windows 的 `npm run dist` 也在校验阶段直接失败** —— 与「原功能不动」相冲突。本版移除该字段，并新增 `tests/buildconfig.test.js`：直接用 electron-builder 自带的 `scheme.json` 校验 `win` / `mac` / `dmg` / `portable` / `nsis` 五段配置的键名，这类问题以后进不了发布版。

## ⬆️ 如何更新

- **Windows**：启动器会自动检查更新并下载 `.exe`；也可直接下载本页的 `MC-Launcher-0.2.4-x64.exe`（安装版）或 `MC-Launcher-0.2.4-portable.exe`（便携版）。
- **macOS（Intel）**：下载 `MC-Launcher-0.2.4-x64.dmg` 安装；已装旧版的会在启动器内收到 `.zip` 增量更新。
- 设置页「自动更新」地址填 `https://github.com/wiuw3qde/minecraft-launcher`。

## 已知限制（如实说明）

- macOS 版未做 Apple Developer 正式签名与公证，首次打开需手动放行一次。
- 陶瓦联机的 macOS 系统组件需管理员权限安装一次；若安装后仍无法建立虚拟网卡，请反馈启动器联机页状态与终端日志。
- 所有新数据能力（存档卡片、冒险日记、自动备份）仍是**纯本地处理，不上传、不上云**。
